# Expense Tracker App

A full-stack MERN Expense Tracker application to manage personal income and expenses efficiently.

## Features

- User authentication (Signup/Login)
- Add, edit and delete income records
- Add, edit and delete expense records
- Dashboard with financial summary
- Income and expense tracking by category
- Visual charts for financial insights
- Export transaction data to Excel
- Responsive user interface

## Live Demo

Frontend: [Expense Tracker App](https://expense-tracker-app-frontend-upx7.onrender.com/login)

## Tech Stack

### Frontend

- React.js
- Vite
- Tailwind CSS
- Axios
- Recharts

### Backend

- Node.js
- Express.js
- MongoDB
- JWT Authentication

## Run Locally

Clone the repository:

```bash
git clone https://github.com/Mdafzaal/Expense-Tracker-App.git
cd Expense-Tracker-App
Install frontend dependencies:
cd frontend
npm install
npm run dev
Install backend dependencies:
cd ../backend
npm install
npm start
Environment Variables
Create a .env file inside the backend folder:
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=your_jwt_secret_key
PORT=5000
Create a .env file inside the frontend folder:
VITE_API_URL=your_backend_url
Author
Mohd Afzaal
```
